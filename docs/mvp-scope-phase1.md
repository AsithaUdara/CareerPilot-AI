# Phase 1 MVP Scope (Frozen)

## Included

1. Resume upload endpoint and plaintext parsing fallback.
2. Candidate profile extraction (summary + core skills).
3. Multi-agent orchestration pipeline:
   - ResumeAnalysisAgent
   - JobMatchingAgent
   - SkillGapAgent
   - LearningPlannerAgent
   - ResumeOptimizationAgent
   - InterviewCoachAgent
4. Explainable unified report payload.
5. Seven-day action plan generation.
6. Frontend screens for upload, readiness dashboard, roadmap, and interview plan.

## Explicitly Deferred

1. Real authentication and user accounts.
2. Production-grade PDF/DOC resume parsing.
3. Live job-board integrations and external course providers.
4. PostgreSQL persistence and vector database deployment.
5. Notifications/reminders and institutional analytics dashboards.
